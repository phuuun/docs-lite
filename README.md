# docs-lite

Tiny plain text writing app. Dark, no toolbar, just write.

- File tree of `~/Documents` on the left, right click to add/rename/delete
- Autosave, word count, session word goal
- Ctrl+F find, Ctrl +/- zoom the text
- Import `.docx`, `.html` or `.txt` (saved as `.txt`)

## Run

Needs Python 3, GTK 3 and WebKit2GTK 4.1 (`python-gobject`, `webkit2gtk-4.1` on Arch).

```sh
python3 docs.py
```
